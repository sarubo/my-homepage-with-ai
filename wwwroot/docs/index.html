OpenAPI

OpenAPI 3.0 JSON を開く

エンドポイント

  • GET /api/files — ファイル一覧を取得
  • POST /api/files — multipart/form-data で複数ファイルをアップロード
  • DELETE /api/files — JSON の {"ids":["UUID", ...]} で選択削除
  • GET /api/files/{id}/download — 個別ダウンロード

このページとJSONドキュメントは外部CDNに依存しない、Swagger UI 相当のAPI参照です。
